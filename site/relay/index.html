Self-host the relay

The relay is a Cloudflare Worker. Off-machine agents post jobs there, and your local daemon pulls them onto the board. A free Cloudflare account and Node.js are enough. If you do not want to run Cloudflare yourself, Hosted Relay is the no-setup option.

Agents that are not on this machine

Cloud and remote agents, for example Cursor cloud agents, CI, and other servers, cannot reach 127.0.0.1 on your machine. They must post to a relay with a write token stored as a secret. Your local daemon pulls those jobs in.

Set it up

  1. 01
    Deploy the Worker

    From a free Cloudflare account, with Node.js installed:

    cd relay
npm install
npx wrangler login
npx wrangler deploy

    wrangler deploy prints the workers.dev URL.

  2. 02
    Set the admin secret

    Never commit it.

    openssl rand -hex 32 > admin-token
npx wrangler secret put ADMIN_TOKEN < admin-token
chmod 600 admin-token
  3. 03
    Create a workspace and tokens

    RELAY_URL is the workers.dev URL from deploy.

    export RELAY_URL=https://statuspan-relay.<account>.workers.dev
export ADMIN_TOKEN=$(cat admin-token)
node scripts/admin.mjs create-workspace home
node scripts/admin.mjs mint home --kind write --agent MyBot --label laptop --out write-token
node scripts/admin.mjs mint home --kind read --label board --out read-token
chmod 600 write-token read-token
  4. 04
    Point the daemon at the relay

    Put relay.json in the data directory. On macOS that is ~/Library/Application Support/statuspan/relay.json.

    {"url":"https://statuspan-relay.<account>.workers.dev","workspace":"home","read_token":"<paste the read token>"}

    chmod 600 that file and restart the daemon. It polls about every 3 seconds. Alternative environment variables: STATUSPAN_RELAY_URL, STATUSPAN_RELAY_WORKSPACE, and STATUSPAN_RELAY_READ_TOKEN.

  5. 05
    Have agents post

    Set STATUSPAN_RELAY_URL, STATUSPAN_RELAY_WORKSPACE, and STATUSPAN_TOKEN_FILE (or STATUSPAN_TOKEN as a secret). Then statuspan post or statuspan run, or curl with Authorization: Bearer.

    curl -s -X POST "$RELAY_URL/v1/w/home/jobs" \
  -H "Authorization: Bearer $(cat write-token)" \
  -H 'Content-Type: application/json' \
  -d '{"agent":"MyBot","job_id":"build-1","state":"running","progress":40}'

Token roles

TokenWhat it can doRole
Write token Belongs to one agent. Post-only. It cannot read the board. Post
Read token Feeds the board (list, poll, and stream). It cannot post. Board
Admin token Creates workspaces and mints, lists, and revokes tokens. Never give it to bots. Admin
